# 01 · IP5306 移动电源 — 镜头清单

来源：`refs/datasheets/IP5306.pdf` 第 11 节「典型应用原理图」（`schematic-typical-app.png`，4 LED 版本）。
封装：ESOP8，**底部有散热焊盘**，热风焊接前必须在焊盘印锡膏，这是本片最适合做特写的镜头。
提示词要求：电阻、电容均 1206；2 oz 铜；Type-C 输入；保留 VIN / VOUT / BAT 测试点。

## 镜头顺序（约 28 段，总长 4–5 min）
0 原理图 → 1 空板 → 2 锡膏（含 ESOP8 底部焊盘特写）→
3 U1 放置 + 热风 + **自对中特写** →
4 L1 → 5–12 电容 C1…C8（可两颗一镜）→ 13–19 电阻 →
20–23 D1–D4 → 24 S1 → 25 Type-C 座 →
26 洗板 → 27 Type-C 线接入，`VIN 5.0 V` →
28 `BAT 3.4 → 4.2 V`（Remotion 数字渐变）同时 D1→D4 依次点亮 →
29 万用表 `VOUT 5.00 V` 保持不变 → 30 成品旋转。

> 注意：IP5306 的 LED 显示的是电量档位，不是电压。镜头 28 用「电池电压上升、LED 依次点亮」表达即可。
