# 原始提示词（来自表格 sheet「6-贴片电容的种类和选取规则」）

视频制作任务：贴片电容的材料、耐压与工程应用选型指南

一、制作目标

制作一部具有专业工程培训价值的电子技术科普视频。

视频主题：

《贴片电容怎么选？从介质材料、耐压到电路应用，一次讲透》

视频面向：

硬件工程师

PCB设计工程师

电源工程师

嵌入式系统工程师

电子工程专业学生

电子元器件采购与选型人员

视频必须同时满足：

1. 技术准确性：内容以电子元件制造商的公开技术资料及器件规格书为依据。

2. 高度直观性：通过三维结构、动态电路、电压变化、容量变化、温度曲线，让抽象参数变得容易理解。

3. 优秀观赏性：达到工业科技纪录片的视觉水准，而不是普通PPT教学。

4. 实际参考价值：工程师观看后，能够根据电路电压、频率、精度、温度和空间限制做出初步选型。

5. 可复用的专业信息：关键参数形成清晰的图表，方便工程师暂停视频截图保存。

所有电容参数必须明确区分：材料类别的一般特性、具体型号的额定参数、演示用假设数据。

二、视觉风格要求

采用高端工业技术纪录片风格。

画面设计：

深色科技工业背景。

银白色电子器件及真实PCB材质。

蓝色、青色表示电场和正常电流。

橙色表示器件发热。

红色表示超出规格或潜在失效。

使用3D CAD级别的贴片电容结构模型。

使用精确的二维工程曲线、坐标轴及参数标签。

关键场景采用真实PCB布局与三维模型相结合的表现方式。

镜头语言：

微距拍摄贴片电容。

镜头进入MLCC内部，展示多层电极与陶瓷介质。

透视展示不同材料的结构差异。

使用分屏画面对比两种或多种电容。

让电压、电流、容量变化与实际图表同步出现。

使用动态数据卡展示参数。

避免不必要的炫光、夸张爆炸、虚假的电子流动。

所有中文字符、单位、数字、材料名称必须清晰准确，避免AI生成错字。

采用专业中文男声配音，语速适中，技术讲解准确自然，字幕与画面同步。

三、详细视频分镜

第一章：为什么外观相似的贴片电容，性能却可能完全不同？

时长：0:00–0:40

画面：

微距镜头缓缓推进PCB，出现多个外观相似的0402、0603、0805、1206贴片电容。

镜头放大同为0603封装的两个MLCC。

两个器件分别标注：

10nF / C0G / 50V

10µF / X5R / 6.3V

注明以上为示意规格，具体型号以数据手册为准。

镜头旋转并进入元件内部，显示不同材料介质。

旁白：

“同样都是贴片电容，为什么有的适合高精度振荡电路，有的适合电源去耦？为什么一个标称10微法的电容，装进实际电路后，容量可能大幅下降？”

“答案，不只是容量和耐压，更在于电容内部的介质材料。”

画面最终显示：

电容选型的五个维度：

介质材料、额定电压、有效电容、温度特性、频率特性。

第二章：贴片电容的主要类型和材料

时长：0:40–1:50

展示五种主要类型：

A. MLCC多层陶瓷电容

内部结构：陶瓷介质与金属电极交错叠层。

重点分类：

Class 1：C0G / NP0

Class 2：X7R / X5R / X8R

Y5V：容量变化较大的第二类陶瓷介质

解释：

C0G介质稳定、损耗低、直流偏压影响很小，适用于精密模拟及谐振电路。

X7R、X5R具有更高的介电常数，更适合在小体积中获得较大容量，常用于滤波和去耦。

B. 钽电容

展示钽粉烧结多孔阳极、氧化层及阴极结构。

区分二氧化锰型与聚合物型。

适合紧凑型电源储能与滤波，但必须考虑浪涌、纹波、电压降额与失效风险。

C. 铝电解电容

展示铝氧化膜与电解质结构。

说明其较大的容量、极性、寿命与温度相关性。

适合电源输入、低频平滑和较大能量缓冲。

D. 导电聚合物电容

展示聚合物作为电解质或阴极材料的结构。

说明它与钽、铝基材并不是互斥分类。

强调低ESR、较好的纹波处理能力，以及不同型号的额定电压差异。

E. 薄膜电容

展示聚丙烯、聚酯等介质薄膜结构。

说明高稳定性、低损耗和部分高耐压应用优势。

指出薄膜电容可以采用SMD结构，但通常比相同容量的MLCC体积更大。

以五类电容的三维模型并列结束本章。

第三章：C0G、X7R、X5R和Y5V究竟有什么区别？

时长：1:50–3:00

制作完整的三维交互式对比动画。

第一组：温度特性。

横轴：温度°C。

纵轴：电容量相对变化%。

显示：

C0G：-55°C至+125°C，温度系数0±30ppm/°C

X7R：-55°C至+125°C，规定条件下容量变化±15%

X5R：-55°C至+85°C，规定条件下容量变化±15%

Y5V：-30°C至+85°C，规定条件下容量变化+22%/-82%

注明：此处为介质温度特性分级标准，不能直接理解为所有条件下的总容量误差。

第二组：直流偏压效应。

演示两个标称相同容量的陶瓷电容：

一个C0G，一个X7R。

随着直流电压增加，C0G的容量基本保持稳定，X7R的实际电容量可能下降。

曲线明确标记“示意曲线，非特定型号实测值”。

说明X5R、X7R的容量下降程度取决于具体料号、尺寸、额定电压及内部设计，并非固定比例。

第三组：应用场景。

C0G：

高精度定时、RF匹配、LC谐振、稳定滤波。

X7R：

工业电源去耦、较宽温度范围的旁路及滤波。

X5R：

常规数字电路、MCU去耦、空间受限的消费电子。

Y5V：

仅用于能容忍较大容量变化、且经过有效容量验证的非关键应用。

第四章：不同材料的耐压究竟有何不同？

时长：3:00–4:10

画面中心出现一条从低电压到高电压的工程电压刻度。

依次展示：

6.3V、10V、16V、25V、50V、100V、250V、630V、1000V及以上。

重点：

不能把材料类型简单等同于某个固定耐压值。

同一类型电容存在多个额定电压档位。

耐压能力与以下因素共同相关：

介质材料的击穿特性

有效介质厚度

电极结构

层数

封装尺寸

制造工艺

温度

寿命与可靠性目标

制作两组三维结构动画。

第一组：

对比相同介质、相近封装的MLCC。

提升额定电压通常需要改变介质层厚度或内部结构。

强调在相同尺寸、相近工艺条件下，容量与额定电压经常存在取舍。

第二组：

一个标称10µF、额定电压16V的X5R电容应用在12V电源轨。

通过模拟曲线展示其容量可能受到直流偏压影响。

禁止使用虚构的准确容量损失百分比。

结论：

额定电压高于工作电压，并不意味着电容的有效容量必然满足需求。

第五章：真实硬件工程场景中的电容选型

时长：4:10–6:20

分别展示四种真实电路。

场景一：MCU供电去耦

3.3V MCU、电源引脚、GND及附近的MLCC。

推荐分析：

X5R或X7R

0.1µF作为常见局部去耦起点

根据器件规格书配置1µF或其他容量的局部储能

注意有效容量、布局及回流路径

将MLCC放置于电源引脚附近

必须强调：具体数量和容量按MCU及电源芯片官方设计指南确定。

场景二：高精度模拟电路

展示精密放大器、ADC、LC滤波网络。

对比C0G与X7R。

解释：

在电容量变化会直接影响频率、增益或精度的关键位置，优先评估C0G。

场景三：12V/24V工业电源

展示DC-DC转换器与输入输出电容。

讲解：

电压裕量

电源瞬态尖峰

有效电容

纹波电流

ESR

温度与寿命

展示MLCC与聚合物、铝电解电容组合使用。

不指定未经验证的统一耐压档位，而是通过最大瞬态电压和规格书选择额定电压。

场景四：高压功率电路

展示工业变频器或功率转换器。

对比高压C0G、适合的薄膜电容，以及经认证的安规电容。

强调：

高频谐振、直流母线、交流安规跨线并不是同一种工况。

X/Y安规位置必须选择适用安规认证的专用电容，不能仅根据额定电压用普通MLCC替代。

第六章：工程师最常见的五个选型误区

时长：6:20–7:20

使用错误案例动画逐个讲解。

误区一：

“电容量相同就可以直接替换。”

解释介质、电压、有效容量、ESR、ESL可能不同。

误区二：

“额定16V的电容用于12V，一定没有问题。”

解释工作峰值、瞬态、电压降额和有效容量。

误区三：

“X7R永远比X5R好。”

解释温度范围差异不等于所有电性能更好。

误区四：

“容值越大，去耦效果一定越好。”

解释频率响应、ESL、布局和电源完整性。

误区五：

“只要耐压高，就可以用于任何高压场合。”

解释交流额定值、脉冲能力、纹波电流及安规要求。

第七章：最终工程选型速查

时长：7:20–8:00

最后形成全屏工程决策图。

依次提出五个问题：

1. 电路实际最大工作电压是多少？

2. 电容容量是否要求高精度和低漂移？

3. 工作温度范围是多少？

4. 工作频率与纹波电流如何？

5. 在实际直流偏压及温度下，有效容量是否足够？

输出直观的推荐路径：

精密谐振、RF匹配 → 优先评估C0G。

常规数字去耦 → 优先评估X5R / X7R。

宽温环境去耦 → 优先评估X7R / X8R及对应车规或工业等级。

较大容量电源缓冲 → 评估铝电解、聚合物、钽电容。

高压谐振或脉冲应用 → 评估合适的薄膜电容或高压C0G。

交流安规位置 → 选择具有对应认证的X/Y安规电容。

最后出现：

“正确选电容，不是只看容量与耐压，而是在真实工况下确认它是否仍然满足电路要求。”

四、工程技术图表要求

必须生成以下六张可独立截图的参考图。

1. 贴片电容类型与介质材料对比表。

2. C0G、X7R、X5R、Y5V温度特性对比图。

3. C0G与Class 2 MLCC直流偏压特性示意曲线。

4. 电容额定电压、工作电压、瞬态电压关系图。

5. 不同类型电容的应用场景推荐矩阵。

6. 硬件工程师贴片电容选型流程图。

所有图表使用统一单位、清晰图例、合理比例和规范工程符号。

只要不是具体厂家数据，就必须注明“示意”或“典型特性”。

五、制作技术要求

视频：3840×2160，16:9，60fps。

画面：

使用三维建模完成器件剖面。

使用矢量图形制作所有技术数据与曲线。

动画与旁白严格同步。

重要数值保持足够长的画面停留时间。

每15–25秒至少出现一次有信息价值的视觉变化。

转场简洁、科技感强，但不影响阅读。

音频：

专业中文男性旁白。

背景音乐采用克制的工业科技风格。

重要结论通过轻微音效强调。

技术讲解过程中音乐音量降低。

字幕：

使用准确简体中文。

电子工程术语同时给出英文缩写。

例如：直流偏压效应（DC Bias Effect）。

电容单位统一使用pF、nF、µF。

所有电压必须标明V DC、V AC或适用的电压条件。

六、技术审核要求

制作前必须建立技术事实清单，并以Murata、TDK、KYOCERA AVX、KEMET等制造商公开技术资料及相关标准为依据。

尤其需要防止以下问题：

混淆材料和温度特性代码。

直接给每种材料指定唯一耐压值。

将某一款MLCC的DC Bias曲线当成所有产品的通用曲线。

将额定电压与实际击穿电压混为一谈。

忽略MLCC的温度、频率与老化特性。

错误地将导电聚合物电容和钽电容定义成完全互斥的材料体系。

以单一额定电压判断安规适用性。

将演示数据伪装为真实测量数据。

出现技术冲突时，优先使用准确数据，不为了追求动画效果牺牲技术正确性。

七、最终交付

输出完整的视频工程及可播放的成片。

同时输出：

1. 逐字中文旁白文稿。

2. 时间轴分镜表。

3. 中文SRT字幕。

4. 六张工程选型速查图。

5. 关键技术参数及参考资料。

6. 使用的示意数据与真实厂家数据的区分说明。

如果支持Remotion，则使用Remotion实现动态图表、字幕、参数卡和镜头合成；三维复杂结构使用适合的3D渲染工具完成，再与视频合成。

视频最终目标：

让没有经验的观众理解贴片电容材料差异，让有经验的硬件工程师愿意将视频作为电容选型的初步参考。
